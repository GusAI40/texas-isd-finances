# Texas ISD Finances

Read-only public research tools for Texas school district finance. They use
committed public TEA, Census, and Texas Bond Review Board artifacts and return
source limitations with the figures.

Examples: find the correct Dallas ISD identifier, compare operating spending
and debt service for two districts, or view Texas's long-run finance trends.

Limits: tools do not provide private records, live budgets, predictions, legal
advice, or universal availability. A public endpoint has been connected in one
owner test account; package installation, independent-account installation, and
directory listing remain unverified release gates.

Privacy and data sources: https://txisd.dev/about#privacy and
https://txisd.dev/transparency. Support: https://github.com/GusAI40/texas-isd-finances/issues.
