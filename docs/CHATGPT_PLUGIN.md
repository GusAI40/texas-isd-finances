# ChatGPT plugin handoff

Package source: `plugin/`. The portable `mcp.json` uses the public HTTPS
Streamable HTTP endpoint with no configured credentials.

The current official creator download supplied `plugin/.app.json`, whose mapping
is referenced by `extensions.com.openai.apps`. Its generated identifier is
evidence of the registered public endpoint, not proof that a package install or
directory release works.

Do not treat endpoint registration as a package or directory release. Verify a
fresh test-channel install, all eleven tools, each visual frame, a district
switch, and an independent eligible account before claiming availability.
