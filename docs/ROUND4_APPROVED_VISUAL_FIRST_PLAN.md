## Optional actual-dollar pilot: assessed, deferred

This is not a prerequisite or instruction to add a new feature. Targeted read of `src/api.py`1436–1563 resolves the basis: `/district/{id}/dollar` chooses the selected district's latest usable year, uses finance/breakdown rows from that same year, and divides each district's category amount by its own enrollment. `peer_per_student` is the median of eligible structural peers' unrounded category dollars/student; `state_per_student` is the median of eligible statewide districts, not pooled statewide dollars/student. Cohorts need at least four usable parsed rows. Returned `peer_count/state_count` precede the parsed-row filter and must not be advertised as exact metric sample counts. “Other” has no cohort per-student value in this implementation, so no reference mark is fabricated.

The response calculates `dollars_vs_peers = round((unrounded selected category dollars/student - unrounded peer median dollars/student) * selected enrollment)`. It rounds displayed per-student values separately. Therefore subtraction of rounded labels times enrollment may differ; preserve the returned annual value and state rounding if showing arithmetic. Normalized median category shares are independently rescaled to100 cents; those cents are not the annual-gap input. Same-year monetary comparisons are valid only with their returned category/fund definitions; preserve category codes/components and total/remainder treatment. Do not assert summing independent medians reconstructs a real peer budget. Zero is a value, null is unavailable, negative gaps retain sign, and invalid/missing enrollment prevents a new formula. No savings/forecast meaning follows.

If independent review finds the current visible distinction misleading, a narrowly justified fix may replace the current three-value per-student prose with one true common-scale monetary comparison plus the returned gap/basis. Otherwise retain the existing interface. The approved goal is a clear completed experience, not maximizing the number of plots.
