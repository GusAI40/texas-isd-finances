## Reproduction and limits

Run from repository root in Windows PowerShell. Network state and credentials can change.

```powershell
uv run python scripts/verify_live.py --require-network --expect-revision 73df1896ed0818020ec1c15c06f5ee823db7ec0f --with-query
uv run python scripts/check_static_js.py
uv run ruff check .
uv run python -m pytest -q
git diff --check
```

At audit time, `uv sync --locked --all-extras --dev` used uv 0.11.33/Python 3.12.14; lock, Ruff, static JS 14/14, and 20 contrast pairs per scheme passed. The divider threshold was 1.4, so this is not a WCAG AA certification. Default tests were 1,151 pass/18 fail/31 skip; explicit UTF-8: 1,168 pass/1 fail/31 skip. The remaining failure is CRLF byte metadata; skip dispositions remain needed. No full suite was rerun for docs-only changes.

## Decisions before implementation

1. Fix source-of-truth/precision issues before new visual claims.
2. Establish small public visual tests for the three audiences, then measure usability.
3. Test the existing HTTPS MCP endpoint in actual target hosts before packaging a ChatGPT plugin; retain all 11 bounded read-only contracts.
4. Do not publish a redesign, plugin, MCP App, or refreshed data from this branch.

The protocol docstring's statement that MRTR/input-required handling is absent conflicts with current tool behavior and current MCP documentation. This audit records documentation drift and a planned correction; it does not prove a runtime protocol defect.
