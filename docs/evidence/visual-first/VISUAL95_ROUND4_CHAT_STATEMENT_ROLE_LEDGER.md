# Round-four chat statement-role ledger

This ledger covers the staged chat candidate only. The immutable runtime remains untouched.

| Statement or material | Role in the staged default flow | Retention proof |
|---|---|---|
| Lead conclusion | Visible | `.ta-lead` remains first. |
| Remaining lead text | Visible conservative qualification/context | `.ta-qualification` is outside native details. |
| Chart district, fiscal year, fund/scope and source | Visible | `.ta-chart-record` appears with the chart. |
| Non-chart district, fiscal year, scope and source | Visible | `metadataOf()` precedes the table. |
| Every limitation string | Visible | Each is a `.ta-limit` outside details. |
| Generic heading/list/paragraph blocks | Visible | They have no semantic optionality field, so they stay outside details. |
| Qualified dollar chart | Visible | It remains before exact-row evidence with the existing common zero scale. |
| Exact chart rows | On demand | Native `View full table — N rows` retains every row. |
| Figure cards/calculation controls | On demand | Closed native `Recorded figures and calculations` disclosure. |
| AI-error/privacy warning | Visible | Composer footer keeps the error warning, identifies the random conversation code, asks visitors to omit personal details, and links to the policy. |

No item was treated as optional from its length or wording. This is a visual-first progression for known duplicate/calculation material, not a claim that literal 95% composition was achieved.
