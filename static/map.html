The statewide similarity map · fiscal

Every Texas district, placed by what it IS — colored by what it SPENDS

Each dot is one of districts. Position comes from structure only — size, growth trajectory, funding capacity, local-tax share — so neighbors on this map are true peers. Color shows spending per student. When similar-looking districts have very different colors, that's where the interesting questions live. Hover any dot; click to open that district's dashboard.

Dot size = enrollment spend/student: low → high (by quintile)

Positions: PCA of the exogenous feature space (2 components ≈ 70% of variance) — built by scripts/graph_insights.py. Source: TEA Summarized PEIMS Actual Financial Data · API · dashboard. This is an independent transparency tool, not an official TEA product.
