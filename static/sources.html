Where every number comes from

“Is this accurate?” is not a question you should have to take on trust. Below is every government file this site is built from, with a download link, and every published figure tied to the exact column it came from, the arithmetic done to it, and the test that recomputes it from the state’s own file. Nothing here requires a login, a licence or a records request — you can repeat this work from scratch.

The sources

Summarized PEIMS Actual Financial Data

Texas Education Agency · fiscal 2009–2025, every Texas school district

revenue, spending by object and by function, debt service, capital outlay, payroll, enrolment.

Download the original

Districts file this with TEA and it is corrected over time. The newest year has had the least time to be corrected.

Texas school district bond election results

Texas Bond Review Board · 4,992 decided propositions, 1958–2026

what school debt was asked FOR, the amount, and whether voters carried or defeated it.

Download the original

Corrected 2026-08-11. This entry previously credited the file to compiled county returns from the Secretary of State and stated that no single agency publishes school bond elections statewide. Both were wrong: the Bond Review Board publishes all of them, back to 1958, on the state's own open-data portal, and always had. The site had been shipping a municipal-advisory vendor's Excel export of that same file — two years stale, 404 propositions short, and carrying spreadsheet subtotal rows. verify_sources.py did not catch it because the Secretary of State URL returns 200; it proved the link was alive, not that it was the right link. It now checks attribution as well. Every row carries the Board's own provenance mark in a Source column (TBR, Issuer, OAG, TSB, BB, Other). This is still the only layer joined on district NAME rather than TEA number; scripts/audit_bond_match.py prints the whole join and fails the build if a shared name is resolved without the county agreeing. Two companion files from the former vendor carry a private CRM and are deliberately never ingested — going first-party removes the temptation permanently.

Enhanced Statewide Summary — A–F accountability ratings

Texas Education Agency · 2025 ratings for 9,084 campuses and 1,208 districts, with enrolment and student need; the workbook also carries a longitudinal sheet back to 2011

the A–F rating the state gives each campus and each district, and the component scores behind it.

Download the original

The only campus-level source on this site. Two distinctions survive into every downstream count: 'Not Rated' is missing data rather than failure (525 campuses, all excluded), and Alternative Education Accountability campuses are rated on a different scale and are excluded from the headline with the including-them figure published beside it. No campus is ranked against a campus in another district — the published claim is about the gap INSIDE a district, which is what a district rating conceals.

Local government debt outstanding — school districts

Texas Bond Review Board · fiscal 2005–2025 actual, plus the amortisation schedule for debt already sold out to 2061; 967 districts

principal and interest still owed, split into current interest bonds and capital appreciation bonds, and the year the borrowing clears.

Download the original

The Board's own issuer index and per-issuer series, taken first-party. A commercial aggregator republishes the same data and is how it was found; it is deliberately not the source, because a re-publisher breaks the provenance chain at its first link. Joined to TEA numbers by name plus county via scripts/district_match.py — the index lists three issuers under two names each, so it is deduplicated by the Board's id rather than by name, which is what stops one district's debt being counted twice. Excludes obligations under one year, commercial paper, and special obligations not needing Attorney General approval, per the Board's scope note.

TIGER/Line Unified School Districts, Texas

US Census Bureau (public domain) · 2024 boundaries, 1,005 districts

district geographic boundaries.

Download the original

Charter districts have no attendance boundary, so ~8% of students are not on the map by construction.

Annual Survey of School System Finances (F-33), district file, fiscal 2024

US Census Bureau (public domain) · fiscal 2024, every U.S. public school system

national per-district revenue, spending, and per-pupil current spending on one federal ruler.

Download the original

Current spending is the Census's own concept: it excludes construction, land, debt, and spending for students outside a district's fall membership, so it is deliberately never mixed with the TEA all-funds figures on this site. Dollars in the file are thousands; per-pupil columns are whole dollars. Fiscal 2024, one year behind the TEA data here.

National Public Education Financial Survey (NPEFS), state file, fiscal 2024

National Center for Education Statistics · fiscal 2024, the 50 states, DC and 5 territories

state-level per-pupil current expenditure and the Texas state ranking.

Download the original

PPE15 divides current expenditure (NCE13) by average daily attendance (ADA) — an identity the build asserts for every state. Territories are excluded from the ranking; the artifact says so.

CCD Local Education Agency Directory, SY 2024-25 (v.1a)

National Center for Education Statistics · SY 2024-25, every U.S. local education agency

the Census-to-TEA join: ST_LEAID ('TX-057905') to NCES LEAID (4816230).

Download the original

The NCES district id is NOT derivable from the TEA number by arithmetic (Dallas is 4816230, not 48+057905); this directory is the only published bridge. Keyed by number, so the eleven Texas district names shared by two districts each cannot cross-match. Every Texas F-33 row resolves through it, and the build refuses to write the artifact if the accounting does not balance.

E-Rate Request for Discount on Services: FRN Status (FCC Form 471)

Universal Service Administrative Company · funding years 2016–2026, every Texas funding request

federal E-Rate commitments and authorized disbursements for school connectivity.

Download the original

Sums on this site cover FRNs with status 'Funded' ONLY: a Pending or Cancelled row's funding_commitment_request is the amount the applicant ASKED for, not a commitment, and summing every status inflates a funding year by hundreds of millions of never-granted requests. E-Rate discounts are mostly paid by USAC straight to vendors, so this money appears nowhere in TEA's books.

E-Rate Supplemental Entity Information

Universal Service Administrative Company · every Texas E-Rate entity (applicants and their schools)

the applicant-to-district join: billed entity number to TEA district number.

Download the original

Self-reported in EPC and sparse — Dallas ISD's own row carries no state code at all. Resolution runs three roads (state code verified against the crosswalk, unanimous campus-code prefix of child schools, audited name+county) and REFUSES where they disagree; the one conflict on record is the two Dawson ISDs, a twin name. Charter networks spanning several TEA districts under one applicant number are never attributed to one of them.

CPI-U, annual average

How to check it yourself

  1. Download the original. Every source above links to the agency's own download page. None requires a login or a records request.
  2. Read the exact column. Each measure names the columns it uses and the arithmetic in one sentence. No figure on this site is derived from a column that is not listed.
  3. Run the re-derivation tests. `python -m pytest tests/test_provenance.py` recomputes every headline from the state's own file, longhand, without importing any build script — so a wrong number cannot validate itself.
  4. Check the published files match the source. `python scripts/verify_artifacts.py` rebuilds every artefact and diffs it byte for byte against what this site serves. It is the only check that catches a build script edited and never re-run, or an upstream restatement absorbed silently.
  5. Check the source has not changed under us. tests/fixtures/provenance.json carries a SHA-256 of the financial file every figure is built from. If the state restates a year, that hash stops matching and the tests fail.
git clone https://github.com/GusAI40/texas-isd-finances
cd texas-isd-finances
python -m pytest tests/test_provenance.py    # re-derive every headline from source
python scripts/verify_artifacts.py           # prove the served files match a fresh build

Source fingerprint

The financial file every headline is built from, as captured. If the state restates a year this hash stops matching and the tests fail rather than the change being absorbed silently.

What none of this establishes

  • This is faithful to the source. It cannot make the source right: PEIMS is filed by districts and corrected over time, and the newest fiscal year has had the least time to be corrected.
  • Figures derived from a model — anything comparing results against what student need predicts — are estimates with real uncertainty, and are published with it rather than as facts.
  • The bond layer is joined on district name plus county because the source carries no TEA number. It is 100% matched with none resolved against a disagreeing county, but it is the only layer where that class of error is possible at all.
  • Districts under 500 students have per-student figures that move on a single hire or retirement. They are flagged and kept out of rankings.
  • Nothing here supports a claim about any named individual.
